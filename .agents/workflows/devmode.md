// turbo-all

This workflow updates configuration files to enable development tools and simplify local testing.

### Steps:

1. **Enable Dev Settings**: Update `neutralino.config.json` for development.
   - Set `"enableInspector": true` to allow browser developer tools.
   - Set `"tokenSecurity": "none"` to simplify extension communication during development.
2. **Verify Settings**: Confirm the changes in the configuration file.
