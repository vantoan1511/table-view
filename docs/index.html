Key Features

Everything you need in a modern, lightweight database management workspace.

Rust Extension Core

Connections and queries are offloaded directly to a high-performance Rust core, bypassing slow JavaScript database wrappers.

Inline Cell Editing

Double-click cells to modify data in place, validate types and constraints instantly, and save updates within transactional scopes.

Persistent Workspace

Panel placements, column widths, editor history, and open query tabs are automatically restored across sessions for seamless workflow continuity.
